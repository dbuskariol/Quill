# Quill 0.1.5

A more consistent native workspace, compact review flows and fixes found through a full UI walkthrough.

- Snippets and custom macros share source editing, insertion controls and spacing. Short templates and previews use less empty space; long content remains scrollable.
- New snippets and macros focus their name immediately. Custom macros gain matching toolbar access and native list deletion.
- Group management, Zendesk placeholders, history, draft recovery and backup review use more compact layouts and consistent actions. Custom Zendesk placeholders can be inserted with Return.
- File pickers stay attached to the window or review that opened them. Settings separates template history from complete backups, includes macros in JSON import counts and keeps navigation reachable at narrower widths.
- Fixed a native text-layout crash when switching search results and a Statistics reset confirmation that did not appear.
- Refreshed real native screenshots and documented the observed UI audit and remaining acceptance boundaries.

## Install or update

Requires macOS 26 or later. The signed and notarized universal app supports Apple silicon and Intel. Install in Applications or use Check for Updates. Existing macOS grants retain the same signed identity.
